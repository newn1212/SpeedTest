# Замер скорости интернета

Консольный скрипт на Python. Делает 10 последовательных запросов к указанному адресу, каждый раз дожидаясь полного ответа, и печатает среднее время запроса, общий объём скачанных данных и скорость скачивания.

## Требования

- Python 3.8+
- библиотека `requests`

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python speed_test.py <адрес>
```

Пример (файл ~10 МБ):

```bash
python speed_test.py https://proof.ovh.net/files/10Mb.dat
```

Для точного замера лучше брать файл или картинку побольше (несколько МБ).

## Что выводится

- время и размер каждого запроса;
- количество успешных запросов;
- среднее время одного запроса (секунды);
- общий объём скачанных данных (мегабайты);
- скорость скачивания.

## Единицы измерения

- время: секунды (с);
- объём данных: мегабайты (МБ), 1 МБ = 1 000 000 байт;
- скорость: **мегабиты в секунду (Мбит/с)**, как принято у интернет-провайдеров, и дополнительно мегабайты в секунду (МБ/с). 1 байт = 8 бит.

Скорость считается как `общий объём данных / суммарное время всех запросов`.

## Как это работает

- Время каждого запроса измеряется через `time.perf_counter()`.
- Тело ответа скачивается целиком до остановки таймера.
- Запрос отправляется с заголовком `Accept-Encoding: identity`, чтобы сервер не сжимал данные и считался реальный объём.
- Если запрос завершился ошибкой (таймаут, нет сети, статус 4xx/5xx), он пропускается и не попадает в статистику.
